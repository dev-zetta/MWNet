# Private native source and notice companion, version 3

A new private companion bundle is assembled and every archived member was read back and checked against its SHA256. `MWNet-1.0.0-native-candidate-source-materials-v3.tar.gz` is 894,276,452 bytes with SHA256 `f4649e5248b213503702713b563339c41002ff3641f560c01d37b4a564c89cff`. The [receipt](2026-11-05-native-source-materials-v3.json) binds its preparation procedures, frozen runtime, 10,561 files and material index. The selected upstream inputs comprise 67 unique digests, totaling 858,385,975 bytes: 65 source archives and two patches. The separately included exact runtime source archive retains SHA256 `291abccb3a369d2ee9fa3f6f871aae14b1d901a5e6770db103f6cb46aab95d77`.

The bundle contains the [699-text notice book](2026-11-05-native-notice-material-assembly.md), upstream inputs, selected source manifests, full preserved SDK/transport/dependency-builder source recipes, matched recipe/patch files and captured Homebrew formula sources with their recipe license. It also includes labeled original SDK include/share/ownership snapshots: 3,406 files on ARM, 3,406 on Intel and 3,401 on Windows. Their Boost header trees are excluded because the actual native builds overlaid complete upstream Boost headers; the [exact full Boost input](2026-11-05-native-static-header-sources.md) is supplied separately. These original SDK snapshots are not relabeled as final runner-overlay headers. Captured Homebrew formula files do not recreate unretained installed-keg options or the preserved Intel image's original missing cache bytes.

An initial local SDK snapshot selection handled the Mac archive's prefixed `installed/` layout but selected no Windows members from its root `installed/` layout; directory selection also recursively included excluded Boost headers. That failed selection and partial exports remain preserved and are not accepted snapshots. The corrected separate export selects regular members only, supports both actual root layouts, requires a nonempty selection and verifies exact equality between selected and extracted paths. No SDK archive, native executable or CI verdict was changed.

This is reviewable private preparation material. It is not a claim that sources are already available at a public URL, nor that every binary distribution obligation or native graphical gate has passed. Accepted native packages must be co-delivered with matching material before publication. The original fourteen-source v2 bundle was rehashed and remains unchanged. Published Linux assets and the NUC service remain untouched.
