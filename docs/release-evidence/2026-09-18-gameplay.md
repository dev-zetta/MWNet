archive and its manifest above are unchanged; the local patched runtime is
`build/gameplay-fix/runtime/` and is **not a replacement release artifact**.

Implemented changes:

- The local launcher supplies the detected ESM/BSA content and only selects
  automatic direct connection when a password-file argument is present.
- SecureSession accepts authenticated out-of-order frames within a bounded
  4,096-counter replay window (512 bytes per session). Duplicate and too-old
  frames remain rejected, and authentication failure cannot advance the window.
- Authenticated transport keepalives prevent an otherwise idle character-creation
  dialog from hitting the read deadline. A peer that stops polling still times out.
- An authenticated account with credentials but no completed character record
  resumes character creation instead of attempting to load nonexistent player JSON.
- Quiet actor cells explicitly renew their leases. Renewal requires the current
  server assignment, its matching lease ID, and membership in the loaded cell.
  After a pause, the client waits for confirmation; an expired assignment gets
  a new lease generation. Expired simulation is discarded. Immediate AI/combat
  sends now attach and check the current lease too.
- Cell-change packets include the destination position, and position snapshots
  identify their cell. The server drops snapshots for a different current cell.
  Cell transitions account for bounded travel since the preceding sample, and
  commit position/authorization together. Rejected destinations preserve the old

  bundled spawn/respawn scripts set coordinates before sending the cell.
