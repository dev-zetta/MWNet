The [receipt](2026-11-05-windows-sdk-source-delivery.json) retains the delivery hashes. This does not convert the other 23 Windows DLLs' separate provider/version evidence into SDK byte identity.

All 35 recorded recipe and patch files for these additional components matched exact bytes in the already-preserved SDK vcpkg/dependency-builder archives. Read-only processing copied 29 named upstream notice files verbatim, and the MyGUI patch remains preserved whole. Private staging contains `windows-sdk-actual-provider-mapping.json`, `windows-sdk-additional-sources/`, `windows-sdk-additional-recipes/` and `windows-sdk-additional-source-notices/`. Exact installed SDK headers and broader build recipes remain available in the original SDK inputs; collecting this selection alone is not complete static/header or distribution acceptance.

At this checkpoint the combined completed collections contain 57 unique source-input digests: 55 archives and two patches, deduplicated by actual SHA256. Earlier selected libiconv bytes were reused after their pin was checked, rather than counted again.
