## Decoder fuzz campaign

The four-target Clang/libFuzzer campaign ran from 2026-09-01 03:50:12 UTC to
2026-09-02 03:50:14 UTC with AddressSanitizer and UndefinedBehaviorSanitizer.
Each target ran for 86,401 seconds, for 345,600 aggregate target-seconds and
72,669,269,368 total executions:

| Target | Executions | Peak RSS |
| --- | ---: | ---: |
| Protocol packet codec | 48,261,795,842 | 562 MiB |
| Transport framing | 18,138,063,980 | 588 MiB |
| Authentication | 474,322,029 | 539 MiB |
| Encrypted handshake | 5,795,087,517 | 520 MiB |

The campaign completed with status `passed` and produced no crash artifact.
The retained campaign metadata has SHA-256
`863f0aa7396ef0d0847209aa2da3ab19ded5560dc566a6184131dc25f581f62a`.
This closes the 24 aggregate CPU-hour decoder-fuzz requirement for the tested
commit. It does not replace sanitizer coverage of non-decoder runtime paths.

## Eight-client release soak

The release-profile soak ran from 2026-09-05 06:52:11 UTC to
2026-09-06 06:52:15 UTC. It completed 5,653 connect, gameplay, death, respawn
and disconnect cycles with eight concurrent clients, 75 ms deterministic
latency and 2% unreliable snapshot loss.

| Measurement | Result |
| --- | ---: |
| Dropped unreliable snapshots | 898 |
| Server tick p99 | 7,302 microseconds |
| Serialization p99 | 16 microseconds |
| Maximum queue depth | 8 |
| Initial resident memory | 12,447,744 bytes |
| Peak resident memory | 17,346,560 bytes |
| Final resident memory | 14,561,280 bytes |
| Memory change after warm-up | -8.79735% |
| Inbound traffic | 27,726,337 bytes |
| Outbound traffic | 27,726,337 bytes |

The harness reported no monotonic memory growth, deadlock or queue-limit
violation. The raw metrics artifact has SHA-256
`3464d39b62584618e184700240f17c39c9f5e03bd3bd5d3117812cda8909162d`;
the log has SHA-256
`b11b78d4fdb98635ffa84d60e7a17e90e442771e771c09b6e80cd94a32602bb5`.
The scalar metrics used for future comparisons are retained in
[`1.0.0-alpha.1-performance-baseline.json`](1.0.0-alpha.1-performance-baseline.json).

The baseline executable was a `RelWithDebInfo` GCC 15.2.0 full-dependency
build with SHA-256
`c8df9946c8ebd0c0ddc3ce752dae45c30d9955eae28a3e1805343132d95035dc`.
It ran on Linux 7.1.5 x86-64 on an AMD Ryzen 9 7945HX3D (16 cores, 32 logical
CPUs). Future performance comparisons must use the same profile and a
materially equivalent runner.

This run closes the duration, client-count, latency/loss, lifecycle,
memory-trend and queue-bound portions of the soak gate. The executable was not
sanitizer-instrumented, so the requirement for a sanitizer-clean long-running
runtime remains open. Cross-platform candidate builds, an independent security
review, specialist legal review and the opt-in public beta also remain open.
