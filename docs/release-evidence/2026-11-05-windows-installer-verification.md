# Preserved Windows installer verification procedure

A bounded native workflow is prepared to execute the unchanged Windows installer, SHA256 `959e6d7b03b444d0711138e2930f9e9f1025a29483c01b458b5dea8776bac893`, alongside the original portable ZIP `f8da81b16677c2c1a1086f9fc632fc67a776fadcd915cb61c9929c3c64144b21` from CI42057767417. It performs a fresh MWNet installation on a disposable Windows 2022 runner, compares installed bytes to the portable package, runs actual installed client/server identity and CoreScripts startup/clean exit, and checks uninstall removal and registry cleanup. Native installer execution has not yet been verified by this procedure; no success is inferred from the earlier portable startup result.

The verifier refuses execution outside native Windows GitHub Actions, refuses pre-existing MWNet registrations, requires an already-present admin token and uses a new directory under the disposable workspace. It requests no interactive elevation or host restart. Both original candidate hashes and the exact runtime checkout are required before installation. The frozen CPack hook runs the VC redistributable and removes its `redist` directory, so the expected portable/installed difference is limited to that single redistributable and the generated uninstaller. The native redistributable's own result is not independently observed; a preprovisioned runner cannot qualify its bootstrap behavior on a clean operating system.

The silent install and waited uninstall follow the [official NSIS command-line rules](https://nsis.sourceforge.io/Docs/Chapter3.html): the installation destination and uninstaller directory argument are last, absolute and unquoted. The procedure retains the installer's CRC checking, uses bounded waits, and limits timeout cleanup to the PID tree created by the disposable test. Original installer/ZIP inputs and failed receipts are preserved. This validates neither an upgrade nor graphical gameplay, a Windows desktop OS matrix, complete distribution delivery or private-state migration. Published Linux assets and NUC production are unaffected.
