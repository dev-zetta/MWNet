# Frozen Mac provider API inspection procedure

A separate bounded native workflow is prepared to inspect the unchanged Apple Silicon DMG `20679685dcd60299fa43eed4f2da53008fee9ef5bf3d99fd1565b8fc37f2524f` from CI42059980428 and the unchanged preserved Intel DMG `6aaf2af3432f29382c45277ab41cb7ceb69a994363494bbb8eed54e7a82edda6` from CI42025424431. Ten Apple Silicon and nine Intel provider checks bind exact delivered file hashes to separately recorded version expectations for Qt, libsodium, fontconfig, gettext, the distinct SDK/Homebrew FreeType and libpng libraries, and the delivered brotli decoders. These are pending native checks, not inferred passes from captured Homebrew lists or loader metadata. Existing OpenSSL and startup outcomes are not rerun as new evidence.

Each library is loaded in a fresh generated controller process. The controller is compiled independently from the frozen game runtime, under private disk scratch, with a `Contents/MacOS` executable and a `Contents/Frameworks` symlink to the read-only application bundle. This honors the delivered `@executable_path` references without editing package bytes, load commands or signatures. Every queried symbol must originate in the expected delivered library, verified by `dladdr` and resolved paths. Inherited `DYLD_*` overrides are removed, exact input hashes are checked before and after each probe, and failures retain bounded stdout/stderr and separate controller identities. This layout qualifies the requested provider APIs, not general game execution under a different launch environment.

FreeType checks initialize an instance, read its version and finish it successfully. Brotli checks also decode a tiny self-generated compressed text vector: 31 compressed bytes expand to eight repetitions of `MWNet dependency probe` followed by a newline, totaling 184 bytes. The vector was generated by Brotli encoder version `0x1002000`, quality 5, window 22, generic mode; compressed SHA256 is `39b3b43d672036672cd53b76e421e7e9e680651b664ca412b2c00da1f906a8c4`. This is one bounded decode case, not full codec compatibility, font rendering or game assets. It is relevant to the actual Apple Silicon composition whose decoder alias resolves to 1.2.1 while the common-library alias resolves to 1.2.0; that composition alone is not labeled a runtime failure.

Four Linux-side regressions passed with actual compiled controller/stub libraries, covering the C API signatures, FreeType initialization failures, wrong-provider symbol origins, exact version/functional evidence and malformed responses. The tiny vector also decoded through the actual local native brotli library. The decoder regression selects the compiler's native library path, avoiding an installed 32-bit compatibility library. Actual QtCore and libintl export tables were checked for the expected symbols. These local checks do not establish macOS results; workflow YAML parsing and patch whitespace checks passed. No native outcome, graphical gameplay, full dependency/source acceptance, image regeneration or application resigning is claimed by preparation. Linux publication and NUC production are unchanged.
