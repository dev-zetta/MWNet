# MWNet 1.0.0-alpha.3 release validation

[MWNet 1.0.0-alpha.3](https://github.com/dev-zetta/MWNet/releases/tag/v1.0.0-alpha.3) was published on October 30, 2026 as a development prerelease using protocol 13. Its tag points to runtime source `d871d54894a0774db7dbcaedc3a0955bacbc08b3`. The independently versioned unattended test controller is clean revision `e2bd37b1398a032c1c77e424634f430db8948408`; later CI/QA changes do not relabel the compiled binaries. The [publication receipt](2026-10-30-alpha3-publication.json) verifies the tag, all eleven asset sizes and SHA256 digests, and unauthenticated public HTTP 200 responses.

The final Linux archive passed ten real rendered scenarios and 130 native command checks, plus fourteen real-client control-boundary cases. All 459 manifest files and the actual client/server hashes were verified. Coverage includes normal character creation and an independent engine stat oracle, persistence/fresh-client reconnect, movement/inventory/doors, server-confirmed incoming NPC damage before counterattacking, fists/knockout/health damage, active and queued temporary-effect removal, preserved permanent abilities/statistics, closed dialogue and working input after respawn, two-client inventory replication, and rejected fingerprint/trust/content inputs. No operator gameplay was required. The short recorded workload lasted 65.635 seconds and peaked at 1,164,050,432 bytes of container memory, about 1.08 GiB; this does not estimate populated-server capacity.

Three actual gameplay recordings and reviewed frames remain privately under `build/release-alpha3/ci-linux-d871-refreshed/gameplay-confirmed/`. The read-only server checkpoint confirmed health 188/200 before the punch sequence, followed by the same client value. Failed development runs and the earlier locally predicted damage-oracle failure remain preserved separately. The procedure now rejects transient local prediction as acceptance evidence and does not mutate health to obtain confirmation. See the [reproduction instructions](../AUTOMATED_GAMEPLAY.md) for the distinct runtime and controller pins.

All six native suites passed in the full Linux configuration and in a fresh detached dedicated-only build of the exact runtime source. The latter built eight targets and verified 1,342 compiled repository inputs against Git blobs, with pinned vendor sources checked. The canonical-content validator accepted all 5,460 playable race/class/birthsign/sex combinations. Eighteen runner, nine content and four Lua fixture regressions passed. The separate ASan/UBSan run passed its portable mechanics/protocol/persistence/native-security scope; it does not instrument the graphical client, GNS/discovery/component suites or system libsodium. A two-client synthetic headless test completed 100 cycles and 200 connection/death/respawn/disconnection lifecycles with empty per-connection metrics after every cycle; this is not actual game-actor or long-soak acceptance.

The selected protocol/compiler/source/security jobs passed at the runtime source, including GCC, Clang, MSVC, protocol TSan/ASan/UBSan and security-enabled unit/fuzz smoke. The general automatic workflow's Ubuntu job retained an explicit build-target omission: its full configuration passed all six tests, but dedicated CTest had two NotRun executables. Tooling revision `e2bd37b139` adds those targets; the fresh exact-runtime dedicated build above passed all six with zero NotRun. The original run is not described as green. The redundant tag-triggered run was cancelled after publication rather than repeating the already validated source through the old target list.

The [native Windows/macOS candidate build](https://github.com/dev-zetta/MWNet/actions/runs/40985525262), [Linux package run](https://github.com/dev-zetta/MWNet/actions/runs/40988654477), [Windows validation](https://github.com/dev-zetta/MWNet/actions/runs/40992935464), [Apple Silicon validation](https://github.com/dev-zetta/MWNet/actions/runs/40989030955) and [Intel macOS validation](https://github.com/dev-zetta/MWNet/actions/runs/40992133801) all passed. Native package checks verify source/version/protocol identity, pristine CoreScripts startup and graceful server shutdown. Windows ZIP CRC, AMD64 client/server headers and the included x64 Visual C++ redistributable were also checked. Linux targets Ubuntu 24.04 system-library ABI; macOS applications are ad-hoc signed and not notarized. No owned game content, private profiles, credentials, private keys or cookies are published.
